# JACI site configuration

Generated by `jaci-spack-stack-bootstrap`.

This experimental site follows the HPE CPE latest Spack guidance for Cray
Programming Environment systems, with an additional JACI-validated MPI compiler
environment policy for Autotools packages.

Validated policy:

- use driver-less compiler executables for Spack, not `cc`, `CC` and `ftn`;
- use external CPE packages in `packages.yaml`;
- model `cray-mpich` as an external MPI with `+wrappers`;
- expose absolute CrayPE MPI drivers through `MPICC=/opt/cray/pe/craype/2.7.33/bin/cc`, `MPICXX=/opt/cray/pe/craype/2.7.33/bin/CC`, `MPIFC=/opt/cray/pe/craype/2.7.33/bin/ftn`, `MPIF77=/opt/cray/pe/craype/2.7.33/bin/ftn`, `MPIF90=/opt/cray/pe/craype/2.7.33/bin/ftn`;
- do not patch Spack package recipes.

Current driver-less GCC commands exposed to Spack:

- C: `/opt/cray/pe/gcc-native/12/bin/gcc`
- C++: `/opt/cray/pe/gcc-native/12/bin/g++`
- Fortran: `/opt/cray/pe/gcc-native/12/bin/gfortran`

Current external MPI:

- `cray-mpich@8.1.31+wrappers`
- prefix: `/opt/cray/pe/mpich/8.1.31/ofi/gnu/12.3`

This policy was validated first with a minimal `fftw@3.3.10+mpi+shared`
probe on JACI. PnetCDF additionally requires absolute CrayPE MPI driver paths
because Spack passes `--with-mpi=<cray-mpich-prefix>` to its configure script.
