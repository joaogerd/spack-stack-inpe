# Cookbook

O cookbook reúne receitas práticas para tarefas operacionais comuns.

Cada receita deve seguir esta estrutura:

```text
Objetivo
Quando usar
Pré-requisitos
Comandos
Resultado esperado
Como validar
Riscos e limitações
```

## Receitas

- Instalar o spack-stack.
- Configurar a JACI.
- Adicionar novo site.
- Usar pacotes externos.
- Compilar MPAS-JEDI usando um stack validado.
- Validar CMake FindMPI.
- Resolver problemas comuns.
