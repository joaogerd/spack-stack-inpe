# Arquivos de configuração

## `config.yaml`

Define configurações locais do Spack, como árvore de instalação, diretórios de build e comportamento geral do site.

## `packages.yaml`

Define preferências de pacotes, providers e pacotes externos comuns ao site.

## `packages_gcc-*.yaml`

Define configurações específicas associadas ao compilador usado na concretização.

## `modules.yaml`

Define como o Spack gera módulos de ambiente.

## `mirrors.yaml`

Define mirrors de código fonte ou binários, quando disponíveis.

## `setup.sh`

Carrega o ambiente básico do site antes de criar ou usar o stack.

## `spack.yaml`

Define o ambiente que será concretizado e instalado.
