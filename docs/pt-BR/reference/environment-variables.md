# Variáveis de ambiente

Esta página documenta variáveis usadas pelos scripts operacionais.

## Controle de validação

```text
TEST_ID
FRESH_INSTALL
FORCE_SOURCE_BUILD
INSTALL_JOBS
SPACK_INSTALL_VERBOSE
SPACK_INSTALL_FAIL_FAST
```

## Uso do stack

```text
STACK_TEST_ID
```

## Caminhos da JACI

```text
JACI_PROJECT_ROOT
JACI_WORK_ROOT
JACI_LOG_DIR
JACI_INSTALL_TREE_ROOT
JACI_MPI_WRAPPER_DIR
```

Cada variável deve ser documentada com valor padrão, objetivo, valor esperado e indicação se é específica do site ou do workflow.
