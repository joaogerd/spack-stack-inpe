# Pacotes

Esta página documenta a política de pacotes do `spack-stack-inpe`.

## Camada de site

A camada de site descreve softwares já fornecidos pela máquina HPC e preferências de pacotes necessárias para aquele site.

## Camada de ambiente

A camada de ambiente descreve o stack necessário para um workflow científico.

## Documentação necessária

Para cada decisão importante sobre pacotes, registre:

- nome;
- versão;
- origem;
- módulos necessários;
- premissas de compilador;
- premissas de MPI;
- comando de validação.

## Nota para JACI

Decisões relacionadas a MPI devem seguir a política de drivers CrayPE documentada para a JACI.
