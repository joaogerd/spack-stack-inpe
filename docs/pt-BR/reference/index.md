# Referência técnica

A seção de referência documenta detalhes técnicos usados pelo `spack-stack-inpe`.

Diferente do cookbook, a referência não é um tutorial passo a passo. Ela descreve arquivos, variáveis, scripts, pacotes e regras de validação.

## Tópicos

- Arquivos de configuração.
- Variáveis de ambiente.
- Scripts operacionais.
- Pacotes e externals.
- Compiladores.
- Módulos.
- Overlay Cray MPICH.
- Tags de validação.
