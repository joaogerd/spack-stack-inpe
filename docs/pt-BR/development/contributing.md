# Como contribuir

## Política de branches

```text
main         -> estado estável e publicável
develop      -> branch de integração
docs/*       -> documentação
feature/*    -> novas funcionalidades
fix/*        -> correções
refactor/*   -> reorganizações estruturais
experiment/* -> testes não produtivos
```

## Requisitos para pull requests

Todo pull request deve descrever:

- objetivo;
- escopo;
- site afetado;
- arquivos alterados;
- comandos executados;
- evidência de validação;
- riscos conhecidos;
- pontos ainda não resolvidos.

## Regra de documentação

Toda alteração não trivial na configuração da JACI deve atualizar a página de documentação correspondente.
