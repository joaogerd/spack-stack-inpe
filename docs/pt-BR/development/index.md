# Desenvolvimento

Esta seção define como o `spack-stack-inpe` deve ser mantido.

## Princípios

- Manter `main` estável e publicável.
- Usar `develop` como branch de integração.
- Usar branches temáticos para documentação, correções, funcionalidades e experimentos.
- Documentar toda decisão técnica não trivial.
- Não misturar configuração de site com workflows de aplicação MONAN/JEDI.

## Tópicos

- Como contribuir.
- Estilo de código.
- Testes.
- Processo de release.
- Roadmap.
