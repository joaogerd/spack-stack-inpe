# EGEON legacy

The EGEON material is preserved as historical and operational context.

## Historical role

The earlier `spack-stack-inpe` work focused on EGEON with:

```text
spack-stack 1.7.0
gnu9
OpenMPI
Lmod
SLURM
/mnt/beegfs
```

This phase produced practical installation instructions, shared environment activation patterns and functional tests for NetCDF, HDF5 and MPI.

## Current status

EGEON content should not be treated as the active JACI path. It should be preserved as legacy documentation until it is revalidated using the current repository structure.

## Migration rule

Useful EGEON procedures should become cookbook entries or historical notes. Machine-specific values must not be copied into JACI configuration.
