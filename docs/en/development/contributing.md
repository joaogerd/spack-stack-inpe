# Contributing

## Branch policy

```text
main         -> stable and publishable state
develop      -> integration branch
docs/*       -> documentation work
feature/*    -> new functionality
fix/*        -> corrections
refactor/*   -> structural changes
experiment/* -> non-production tests
```

## Pull request requirements

Every pull request should describe:

- objective;
- scope;
- affected site;
- files changed;
- commands executed;
- validation evidence;
- known risks;
- unresolved points.

## Documentation rule

Every non-trivial change to JACI configuration must update the corresponding documentation page.
