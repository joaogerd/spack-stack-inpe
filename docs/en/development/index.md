# Development

This section defines how `spack-stack-inpe` should be maintained.

## Principles

- Keep `main` stable and publishable.
- Use `develop` as the integration branch.
- Use topic branches for documentation, fixes, features and experiments.
- Document every non-trivial technical decision.
- Do not mix site configuration with MONAN/JEDI application workflows.

- Contributing.
