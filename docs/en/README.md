# English documentation

This directory contains the operational English documentation for preparing, installing and validating the JCSDA `spack-stack` on the INPE JACI machine using the configuration stored in this repository.

## Documents

```text
JACI_STACK_BUILD_STEPS.md
```

Main manual with the complete procedure from preparing the `spack-stack` tree to the final environment validation.

## Current status

The validated repository target is a `spack-stack release/2.1` environment for JACI with:

```text
PrgEnv-gnu/8.6.0
gcc-native/12.3
cray-mpich/8.1.31
CrayPE drivers cc, CC and ftn
Tcl modulefiles generated by Spack
```

The current workflow uses an overlay for the external `cray-mpich`. This overlay makes internal Spack calls such as `self.spec["mpi"].mpicc` resolve to controlled wrapper scripts that call the correct CrayPE drivers instead of using the raw `mpicc`, `mpicxx` and `mpifort` wrappers from the Cray MPICH directory.

## Institutional validation rule

Before creating a tag, another member of the group should execute the complete procedure with a new `TEST_ID`, without reusing old `work`, `logs` or `install` directories.
