# Cookbook

The cookbook contains practical recipes for common operational tasks.

Each recipe should follow this structure:

```text
Goal
When to use
Prerequisites
Commands
Expected result
How to validate
Risks and limitations
```

## Recipes

- Install spack-stack.
- Configure JACI.
- Add a new site.
- Use external packages.
- Build MPAS-JEDI using a validated stack.
- Validate CMake FindMPI.
- Troubleshoot common failures.
