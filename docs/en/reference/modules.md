# Modules

This page documents module usage and module generation policy.

## Module systems

The active JACI work uses Tcl environment modules. Other machines may use Lmod or a different module layout and must be documented separately.

## What to record

- Base module paths added by `module use`.
- Modules loaded by the site `setup.sh`.
- Modules generated by Spack.
- Meta-modules generated by `spack-stack`.
- Required `MODULEPATH` changes.

## Validation commands

```bash
module avail
module list
echo "$MODULEPATH"
```

## Rule

A stack is not considered usable until the generated module tree can be loaded in a clean shell session.
