# Environment variables

This page documents variables used by the operational scripts.

## Validation control

```text
TEST_ID
FRESH_INSTALL
FORCE_SOURCE_BUILD
INSTALL_JOBS
SPACK_INSTALL_VERBOSE
SPACK_INSTALL_FAIL_FAST
```

## Stack usage

```text
STACK_TEST_ID
```

## JACI paths

```text
JACI_PROJECT_ROOT
JACI_WORK_ROOT
JACI_LOG_DIR
JACI_INSTALL_TREE_ROOT
JACI_MPI_WRAPPER_DIR
```

Variables must be documented with their default, purpose, expected value and whether they are site-specific or workflow-specific.
